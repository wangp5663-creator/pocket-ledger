# 小账本 v2.1：实际天数与自定义周期

- 日期：2026-11-06
- 基于：`2026-11-06-pocket-ledger-v2-design.md`
- 状态：已实现

## 1. 规则补充

### 1.1 按当月实际天数折算

- 每个周期有自己的起始月份；该周期的日均按**起始月份的实际天数**折算：
  - `日均正常 = round(月度预算 / 起始月天数)`
  - `日均保底 = round(月度保底 / 起始月天数)`
- 例：600 / 450
  - 30 天月：20.00 / 15.00，整月自由额度 150
  - 31 天月：19.35 / 14.52，整月自由额度约 149.73
  - 28 天月：21.43 / 16.07，整月自由额度约 150
- 周期自由额度 = `(日均正常 − 日均保底) × 周期天数`，自定义短周期会按比例减少自由额度。

### 1.2 周期起始日

- 设置项「周期起始日」：1–31，默认 1。
- 默认周期：从每月起始日（超过当月天数时取当月最后一天）到下一次起始日前一天。
  - 起始日 1 → 每月 1 号到月末。
  - 起始日 15 → 每月 15 号到次月 14 号。
- 修改起始日只影响**下一次恢复**；当前周期沿用开始时的快照。
- 周期起始日会随恢复事件快照保存。

### 1.3 自定义周期

- 设置页「自定义当前 / 未来周期」打开日历，选择开始/结束日期。
- 日历可修改**历史、当前和未来周期**；选定的起止范围成为一个独立周期。
- 范围内已有的周期会被合并；范围前的周期在开始日前一天结束，范围后的周期从结束日次日开始。
- 不要求包含今天；重新划界历史周期后，相关记录、阶段、余额和统计会重算。
- 自定义周期结束后，按默认周期起始日继续（可能产生一个短衔接周期）。
- 自定义周期的预算/保底/自由额度按上述「起始月日均 × 周期天数」折算；使用范围开始时所处周期的预算快照。
- 未来周期在设置页「未来周期」列表中展示；历史/当前周期在统计页查看。
- 自定义范围可以早于应用起始日期：若开始日期更早，应用起始日期随之前移，之前未记录的日期会出现在「补记」中。
- 校验：开始日期不能晚于结束日期。

## 2. 数据模型补充

```ts
interface MealSettingsV2 {
  // ...
  cycleStartDay?: number; // 1-31，默认 1
}

interface RestoreEvent {
  // ...
  cycleStartDay?: number; // 周期开始时的快照，默认 1
}
```

- v2 旧数据没有 `cycleStartDay` 时按 1 处理，无需迁移。
- `RestoreEvent.freeAllowance` 仍保存快照；时间线用「日均差 × 周期天数」实时计算周期自由额度。
- 周期结束日 = 下一恢复日前一天；最后一个周期 = 下次周期起始日 − 1（即使在未来，用于展示计划周期）。

## 3. 界面补充

- 设置页：
  - 周期起始日输入（1–31）；
  - 当前周期显示开始/结束日期；
  - 「自定义当前 / 未来周期」日历；
  - 未来周期列表；
  - 日历内错误提示（不藏在弹层后面）。
- 引导页默认起始日期 = 当月 1 号。
- 统计页只显示已开始的周期；当前周期结束日在未来时标「进行中」。
- 修复 MoneyInput 在 `.field` 内被重复描边的问题（只对 `.field` 直接子输入应用边框）。

## 4. 验收

1. 设置周期起始日 15 后，下个周期为 15 号到次月 14 号。
2. 默认 1 号周期为 1 号到月末；不同月份日均按实际天数变化。
3. 日历可自定义当前周期（如 11/1–11/20），结束后次日开始新周期。
4. 日历可规划未来周期，设置页显示未来周期。
5. 自定义 20 天周期自由额度为整月额度的 20/30（例如 100）。
6. 历史周期也能用日历重新划界，相关记录与统计会重算。
7. 输入框只有一层边框；全部测试与构建通过。
